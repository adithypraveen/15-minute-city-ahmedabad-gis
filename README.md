# 🗺️ 15-Minute City Walkability Index — Central Ahmedabad

An end-to-end GIS spatial assessment evaluating pedestrian accessibility to core daily amenities in Central Ahmedabad using OpenStreetMap (OSM) data and QGIS network analysis.

![15-Minute City Walkability Map](Ahmedabad15mins.jpg)

---

## 📌 Project Highlights
* **Study Area:** Central Ahmedabad (Navrangpura, Ashram Road, Sabarmati Riverfront Corridor).
* **Tools Used:** QGIS, QuickOSM, Network Analysis (Service Area Isochrones), Field Calculator.
* **Methodology:** 1,200m (~15-minute walk) network catchments mapped across a 150m hexagonal grid using a multi-criteria weighted accessibility score (0–100).
